# Madden 20 Online

Play Madden NFL 20 Ultimate Team again — Draft Champions, H2H Seasons vs CPU, packs and the store — on your PC, with a local server and a patched shadPS4.

**You need:** your own extracted Madden NFL 20 PS4 game (CUSA13265, version 01.00), Windows 10/11 64-bit, a Vulkan GPU, a controller.

1. Download **Madden20Online-Setup.exe** from [Releases](../../releases) and run it.
2. Pick your game folder → **Install**.
3. Open **Madden 20 Online** from the desktop → **Download card data** (once) → **Play**.

The exe isn't code-signed: if Windows says "Windows protected your PC", click **More info → Run anyway**. If it asks to allow network access, allow it (the server only runs on your PC).
